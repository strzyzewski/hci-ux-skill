B1 contact-form: Build a contact form as a single React + TypeScript component file (no external UI libraries; plain CSS-in-file or a <style> string is fine). Fields: name (required), email (required, must be a valid email address), phone (optional), message (required). It submits JSON to POST /api/contact, which may answer 201, 422 with {errors: {field: message}}, or 5xx. Used by visitors of a company website on desktop and mobile.
B2 delete-project: Build the delete flow for a "Project" in a project-management web app as a single React + TypeScript component file. A project has dependent items (tasks, files, members). API: GET /api/projects/:id/dependencies -> {tasks: number, files: number, members: number}; DELETE /api/projects/:id (permanent); POST /api/projects/:id/archive and POST /api/projects/:id/unarchive also exist. Used daily by team leads on desktop.
B3 csv-import: Build the UI for a CSV contact import as a single React + TypeScript component file. Imports of large files take 10 s to several minutes. API: POST /api/imports (multipart file) -> {id}; GET /api/imports/:id -> {status: "running"|"done"|"failed"|"cancelled", processed: number, total: number, errors: [{row: number, message: string}]}; DELETE /api/imports/:id cancels a running import. Used by office staff on desktop a few times per month.
